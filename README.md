# Teddys dag

Interaktiva bildberättelser för små barn (ca 2–3 år) där gosedjuret Teddy övar vardagssituationer. Spela tillsammans och prata om det som händer.

Berättelser:
1. **Först hem, sen leka** – först–sen, att inte stanna på vägen hem.
2. **Stopp vid vägen** – lyssna på vuxna, de ser faror man inte ser själv.
3. **När Teddy blir arg** – stor och snäll, vad man gör i stället för att bita (blåsa ljus, stampa, säga STOPP, krama kudden, hämta en vuxen).
4. **Turas om** – dela gungan, först Teddy sen Mus.
5. **Förlåt och trösta** – säga förlåt, trösta och hjälpa till.

Allt läses upp med svensk datorröst. Håll in kugghjulet en sekund för inställningar, där kan du spela in din egen röst för varje replik (sparas bara på enheten).

Statisk webbapp utan beroenden: `index.html`, `style.css`, `art.js` (SVG-bilder), `app.js` (berättelser), `sw.js` (offline).
